# Прогнозирование оттока клиентов телеком-компании

## Описание проекта

Оператор связи «ТелеДом» хочет бороться с оттоком клиентов. Для этого его сотрудники будут предлагать промокоды и специальные условия всем, кто планирует отказаться от услуг. Чтобы заранее находить таких пользователей, компании нужна модель, которая сможет предсказывать, разорвёт ли абонент договор.

## Описание услуг

Оператор предоставляет два основных типа услуг:

- **Стационарная телефонная связь** — телефон можно подключить к нескольким линиям одновременно.  
- **Интернет** — подключение через телефонную линию (DSL) или оптоволоконный кабель (Fiber optic).

Дополнительные услуги:

- **Интернет-безопасность:** антивирус (DeviceProtection) и блокировка небезопасных сайтов (OnlineSecurity)  
- **Выделенная линия технической поддержки (TechSupport)**  
- **Облачное хранилище файлов (OnlineBackup)**  
- **Стриминговое телевидение (StreamingTV)** и каталог фильмов (StreamingMovies)  

Клиенты могут оплачивать услуги ежемесячно или заключить договор на 1–2 года. Также доступны разные способы оплаты и электронные чеки.

## Описание данных

Данные состоят из нескольких файлов, полученных из разных источников. Все файлы содержат столбец `customerID` — идентификатор клиента.

### Файл `contract_new.csv`

- `BeginDate` — дата начала действия договора  
- `EndDate` — дата окончания договора  
- `Type` — тип оплаты (ежемесячно или раз в год-два)  
- `PaperlessBilling` — электронный расчётный лист  
- `PaymentMethod` — способ оплаты  
- `MonthlyCharges` — ежемесячные расходы  
- `TotalCharges` — общие расходы абонента  

### Файл `personal_new.csv`

- `gender` — пол  
- `SeniorCitizen` — пенсионер или нет  
- `Partner` — есть ли супруг/супруга  
- `Dependents` — есть ли дети  

### Файл `internet_new.csv`

- `InternetService` — тип подключения  
- `OnlineSecurity` — блокировка опасных сайтов  
- `OnlineBackup` — облачное хранилище  
- `DeviceProtection` — антивирус  
- `TechSupport` — линия технической поддержки  
- `StreamingTV` — стриминговое ТВ  
- `StreamingMovies` — каталог фильмов  

### Файл `phone_new.csv`

- `MultipleLines` — подключение телефона к нескольким линиям  

Все данные актуальны на **1 февраля 2020 года**. Дatasets находятся в папке `/datasets/`.

## План работы

1. **Загрузка данных** — первичный осмотр каждого файла.  
2. **Исследовательский анализ и предобработка** — анализ признаков и обработка пропусков или аномалий.  
3. **Объединение данных** — создание одного датафрейма по ключу `customerID`.  
4. **Анализ объединённого датафрейма** — визуализация распределений, корреляционный анализ, генерация новых признаков.  
5. **Подготовка данных** — кодирование категориальных признаков, масштабирование числовых.  
6. **Обучение моделей** — как минимум две модели с подбором гиперпараметров.  
7. **Выбор лучшей модели** — оценка качества на тестовой выборке.  
8. **Выводы и рекомендации** — основные результаты и предложения для бизнеса.
